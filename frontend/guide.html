Operator guide

How to use CUBE Operations during the live demo

Follow this path to run a workflow, explain the result, inspect evidence and show human control.

Start workflow

Best demo path

Sign in -> UNIT-0014 -> Run -> Evidence -> Override -> UNIT-9004

This order shows the business problem, FBA routing, evidence trace, recovery impact and MFN routing in one clean story.

Sign inRunEvidenceOverrideImpact

Use these demo units

UNIT-0014
FBA returned unit, claim recommended.
UNIT-9003
Clean FBA path.
UNIT-9004
MFN pack route.

1. Sign in

Select org_demo_alpha and enter the alpha token from .env. This creates a tenant-scoped session.

Success: the Run workflow section appears.

2. Run workflow

Choose a demo unit and click Run workflow. The timeline shows which stages completed or were skipped.

Success: UNIT-0014 shows claim recommended.

3. Load evidence

Open Evidence Trace to show verdicts, reasons, confidence, inputs, upstream refs and hashes.

Success: current records show PASS, PASS, PASS and Recovery FAIL.

4. Override if needed

Select a record, choose the corrected verdict and enter a reason. CUBE records the override without deleting original evidence.

Success: the override is saved with actor and reason.

What To Click

Use this when you are presenting and want a simple checklist.

01Open Console

Click Console in the sidebar or open /. Start at the overview so judges see the business story and system health.

02Select Unit

Choose UNIT-0014. Keep route as FBA and returned checked.

03Run Workflow

Click Run workflow. Wait for the outcome card and stage timeline.

04Open Evidence

Click Load evidence. Expand records and show reasons, checks and refs.

05Show MFN

Pick UNIT-9004. Run it to show MFN goes through Pack.

06Close Strong

Return to Business case and summarize impact: faster ops, fewer misses, audit-ready decisions.

What To Say

Short lines you can use while showing the UI.

Problem"Amazon sellers need one place to connect receiving, prep, returns and recovery decisions."
Solution"Each agent owns one ecommerce role and produces audit-grade evidence."
Trust"If evidence is missing, the system shows uncertainty instead of pretending."
Impact"The result is faster handling, fewer mistakes and clearer recovery claims."

How To Read The Screen

Simple meaning of the main UI areas.

Outcome cardThe business answer: clean, blocked, incomplete or claim recommended.
TimelineWhich agent ran, passed, failed or was skipped.
Evidence traceWhy the system made the decision and what sources it used.
Override formWhere a human records a corrected decision with a reason.
